## Objetivo de esta documentación

Esta carpeta concentra la evidencia técnica y académica del prototipo Cuentas Claras.

No es solo un manual de uso. Sirve para demostrar ante el tribunal que el proyecto tiene:

- fundamento contable;
- diseño de sistema;
- implementación técnica verificable;
- ciclo contable documentado;
- control de datos;
- alertas preventivas;
- reportes comprensibles;
- respaldo y trazabilidad;
- despliegue público;
- límites profesionales claramente declarados.

## Mensaje central del proyecto

Cuentas Claras no pretende reemplazar al Contador Público Autorizado.

Es una herramienta académica de apoyo contable digital, control documental, cálculo tributario preventivo, generación de reportes y educación contable para microempresas comerciales de Trinidad, Beni.

Su valor está en demostrar que un modelo de gestión contable digital puede ser:

- simple;
- accesible;
- preventivo;
- educativo;
- técnicamente verificable;
- adaptable a la realidad del microempresario local.
